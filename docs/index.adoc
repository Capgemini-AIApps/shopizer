== Introduction

This documentation provides comprehensive retro-documentation of the Shopizer e-commerce platform source code. The documentation is organized by module and covers key components of the system.

Shopizer is a headless commerce REST API for e-commerce applications built with Java and Spring Boot. It provides comprehensive functionality for:

* Product catalog management
* Shopping cart operations
* Checkout and payment processing
* Customer management
* Order management
* Merchant administration
* Multi-language and multi-currency support

== Repository Structure

The Shopizer repository is organized into the following main modules:

[cols="1,3", options="header"]
|===
|Module |Description

|`sm-shop`
|Main web application module containing REST API controllers, facades, security configurations, and application entry point

|`sm-core`
|Core business logic module containing services, repositories, and business process implementations

|`sm-core-model`
|Domain model module containing entity classes representing the business domain

|`sm-core-modules`
|Integration modules for external services like shipping, payment, and utilities
|===
